# Studio HQ redesign draft (Artlist concepts)

**Status:** concept only. No app code touched. Per the UI taste notes, nothing gets built until a mockup is approved.

## Direction: "Tungsten Night"
One warm light source, deep walnut-black surfaces, paper-label beat tickets, brass details, film grain. It avoids glass cards, neon and flat graphite, which were all rejected before.

- Titles: characterful serif. UI: readable sans. BPM, money and time: tabular monospace data face.
- Statuses use stamped glyphs as well as colour.
- Palette: studio black `#0E0C0A`, walnut `#1A1612`, panel `#2A231C`, paper `#F2E8D5`, tungsten amber `#FFB347`, sold vermilion `#E8553D`, live verdigris `#5FB3A1`.

## Structure (from docs/design/studio-hq-v2.md, section 3)
- Six surfaces: Line, People, Ledger, Crate, Rig, plus Beat Sheet opened in place.
- Line home has lanes Inbox, Ready, Out, Earning, with a "since you left" strip and a transport bar with a jobs tray.
- Beat Sheet shows four parallel tracks (Finish, Pitch, Post, Sell) derived from events.

Caveat: the 3.0 build of this same structure was judged "cheap". The structure is not proven; this draft tests whether the new look rescues it, or whether the layout needs rethinking.
