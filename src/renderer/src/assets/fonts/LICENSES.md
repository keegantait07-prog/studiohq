# Bundled fonts

Latin subsets only (the Japanese accents in the themes use the system Japanese font). Downloaded from Google Fonts (fonts.google.com),
where every family below is published under the SIL Open Font License 1.1 (https://openfontlicense.org).

Kiwi Maru, Zen Maru Gothic, Mochiy Pop One, M PLUS Rounded 1c, DotGothic16, Pirata One, Metal Mania, Nosifer. (Barlow Condensed is already bundled by the app's font packages.)
